# 📊 Retail Like-for-Like (LFL) Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analysing retail performance by comparing current-year sales with previous-year sales using Like-for-Like (LFL) analysis in Microsoft Power BI.

The dashboard helps evaluate business growth, compare key performance indicators, and identify changes in retail performance across regions and store formats.

Developed as part of my Data Analytics Fellowship at DataMelon Labs, this project strengthened my understanding of year-over-year performance analysis and interactive dashboard development.

## 🎯 Objectives
- Compare current-year and previous-year retail performance.
- Analyse sales and transaction growth.
- Evaluate changes in Average Transaction Value (ATV).
- Understand regional performance.
- Compare results across store formats.
- Present performance trends through interactive visualisations.

## 📈 Dashboard Highlights
- **LFL Sales Growth:** Analyse changes in sales compared with the previous year.
- **Transaction Growth:** Track changes in transaction volume.
- **ATV Growth:** Understand changes in average transaction value.
- **Regional Analysis:** Compare performance across regions.
- **Store Format Analysis:** Explore performance across different store formats.
- **Interactive Visualisations:** Use charts, tables, and filters to explore results.
